## Google Sites Implementation Notes

### What Translates Directly:
1. **Section structure** — Use Google Sites' section dividers
2. **Typography hierarchy** — Use heading levels (H1, H2, H3)
3. **Color scheme** — Apply via theme customization
4. **Timeline layout** — Use text boxes with styled headers
5. **Country grid** — Use image cards or table layout

### Google Sites Limitations:
- Limited custom fonts (use closest alternatives)
- No custom CSS (design is simplified automatically)
- Limited animation support
- Fixed layout options

### Recommended Google Sites Structure:

```
[HERO BANNER]
- Background: Dark charcoal or gold gradient
- Title block with name
- Subtitle with key message

[DIVIDER]

[ABOUT SECTION]
- Two-column layout
- Left: Main text
- Right: Credentials in text box

[DIVIDER]

[JOURNEY SECTION]
- Use "Table of contents" style or
- Collapsible text sections for timeline

[DIVIDER]

[GLOBAL PRESENCE]
- Image carousel with flags or
- Grid of image cards

[DIVIDER]

[FOUNDATION]
- Two-column with quote callout

[FOOTER]
- Button links to external pages
```
